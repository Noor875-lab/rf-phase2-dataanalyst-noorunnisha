# Grocery Store Sales Data Analysis

## Project Overview
This project focuses on analyzing a grocery retail dataset to extract meaningful business insights using Python, SQL, and dashboard visualization tools.
The objective is to transform raw transactional data into actionable insights that support business decision-making.

## Dataset
**Source:** Kaggle((https://www.kaggle.com/datasets/pratyushpuri/grocery-store-sales-dataset-in-2025-1900-record))
**Name:** Grocery Store Sales Dataset
**Records Include:**
* Transaction details
* Store information
* Product details
* Quantity sold
* Discounts applied
* Final transaction amount
* Loyalty points
* Transaction dates
* 
## Tools & Technologies
* Python
* Pandas
* SQLite (SQL Queries)
* Matplotlib
* Power BI
* Jupyter Notebook (VS Code)
* Git & GitHub

## Data Cleaning Process
* Checked for missing values
* Checked for duplicate records
* Verified data types
* Converted transaction_date to proper datetime format
* Created SQLite database from cleaned dataset
* Validated database schema using PRAGMA

## SQL Analysis (Task 2)
Implemented SQL queries using:
* GROUP BY
* JOIN
* Subqueries

### Business Questions Answered:
* Which store generates the highest total revenue?
* Which products are sold the most?
* What is the monthly sales trend?
* Which stores perform above average sales?
* How do loyalty points vary by store?

## Visualization (Task 3)

Created a Power BI Dashboard including:
* KPI Cards (Total Sales, Total Quantity, Total Transactions)
* Sales by Store (Bar Chart)
* Top 10 Products (Bar Chart)
* Monthly Sales Trend (Line Chart)
* Filters for Store and Product
* Insight Summary section (Non-technical explanation)

## Key Insights
* A few stores contribute significantly higher revenue than others.
* Top-selling products drive a major portion of total sales.
* Sales show monthly fluctuations indicating seasonality trends.
* Some stores perform above the overall sales average, indicating operational efficiency.
* Discount strategies impact final revenue generation.

The analysis highlights how raw retail transaction data can be transformed into meaningful insights that support strategic business decisions.
